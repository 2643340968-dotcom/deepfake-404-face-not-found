在另一台电脑上运行

网页不能自动启动桌面软件。每台电脑首次使用时，需要下载并运行本项目；只安装 Processing 不会开启本机服务。

  1. 安装 Processing 4，推荐 4.5.7，选择 Java 模式。
  2. 下载项目包，完整解压到桌面、文档等可写文件夹。不要直接在 ZIP 里打开；保留 code/ 和 data/。
  3. 在 Processing 中打开 DigitalMaskOnly/DigitalMaskOnly.pde，点击左上角 ▶。不需要修改盘符、安装 Node / Python 或执行 PowerShell。
  4. 首次运行会自动下载对应系统的摄像头依赖，约 40–150 MB。进度显示在 Processing 控制台与窗口标题；保持联网，等候完成。之后会使用本地缓存。
  5. 准备完成后会自动打开本机网页。点击开始后才采集摄像头；如系统提示，请允许 Processing 使用摄像头。也可返回公共页，点击“已运行项目，连接本机”带入定制配置。
  6. 体验结束后退出 Live；不再使用时，在 Processing 中点击停止。运行时不要关闭 Processing。

摄像头、手势和口罩可在没有 Arduino 的情况下使用。真实距离 / Risk 需要 Arduino + HC-SR04；没有传感器时显示未知。

运行条件与排查

提供 Windows x64、Mac Intel / Apple Silicon、Linux x64 的依赖。Windows 已进行实际运行检查；Mac 与 Linux 尚未在实体设备测试。Linux 可能需要系统库、摄像头 / 串口权限。不支持手机、Windows ARM 和 Linux ARM，不保证旧版 Processing 可运行。

本机页面打不开：先确认 ▶ 已运行完毕，再访问 本机体验。下载失败：检查网络是否能访问 GitHub Pages，重新点击 ▶。端口占用：停止之前运行的项目副本后再运行。摄像头无法开启：关闭其他视频软件，并检查系统对 Processing 的摄像头权限。

Quick start

  1. Install Processing 4 (Java mode, 4.5.7 recommended).
  2. Download and fully extract the project ZIP to a writable folder.
  3. Open DigitalMaskOnly.pde in Processing and press Run.
  4. On first Run, stay online while camera dependencies download automatically (about 40–150 MB). Later runs use the cache.
  5. The local website opens when ready. Choose Begin to enable the camera. Keep Processing running; Stop ends the local service.

Supported runtime packages: Windows x64, macOS Intel / Apple Silicon, Linux x64. Physical Windows camera testing only; Mac/Linux are not hardware-verified. Arduino is optional; actual distance requires the sensor. Images are processed locally and are not uploaded or saved.
