# 404 FACE NOT FOUND

Public demonstration of 404 FACE NOT FOUND. Full realtime installation runs locally.

Published site: https://2643340968-dotcom.github.io/deepfake-404-face-not-found/

This repository contains only the existing public browser demonstration. Camera, gesture recognition, sensor input, and complete realtime rendering require the local Processing + Arduino installation. Public archive entries are explicitly fictional demonstration data.
