# 404 FACE NOT FOUND · Browser Live

Public experience: https://2643340968-dotcom.github.io/deepfake-404-face-not-found/

This browser version includes camera-based face and two-hand tracking, L-frame activation, eight configurable digital masks, a clearly labelled distance simulation, and a local interaction archive. Camera frames and landmarks stay in memory on the device. Only event metadata is saved in the current browser; sample records are separately labelled.

The Processing + Arduino installation remains the higher-quality on-site version. The browser distance control simulates the 2–50 cm mapping; it is not a hardware reading or a privacy-protection probability.

MediaPipe Tasks Vision 1.1.1 and the face/hand models are served from this repository, with the Apache license in vendor/LICENSE.txt. No account, server upload or Processing installation is needed for the public browser experience.
